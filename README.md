# Go MVC Catalog Website

A simple web-based catalog / online shop application built using Golang
with MVC (Model-View-Controller) architecture.

This project was created as a learning project to understand backend
fundamentals such as routing, controllers, database interaction,
and server-side rendering.

---

## ✨ Features
- Product catalog
- User authentication (login & register)
- Cart & checkout flow
- MVC architecture (Model, View, Controller)
- MySQL database integration
- Server-side rendered HTML
- Clean and structured project layout

---

## 🛠 Tech Stack
- Golang
- net/http
- HTML & CSS
- MySQL
- Git & GitHub

---

## 📁 Project Structure
config/ # Database configuration
controllers/ # Handle HTTP requests & business logic
helpers/ # Helper functions (auth, session, render)
models/ # Database models
routes/ # Application routing
views/ # HTML templates
public/ # Static files (CSS, images)
main.go # Application entry point


---

## ▶️ How to Run
1. Clone this repository
2. Set up MySQL database
3. Configure database connection in `config/database.go`
4. Run the application:
go run main.go/ u can install ext "air" for live server
5. Open browser at:
   localhost://8080
